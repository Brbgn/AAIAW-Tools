# Source pack | Fictional process evidence

These six fictional records demonstrate how a process can be reconstructed from mixed sources. They do not contain actual company policies or communications.

| Reference | Source | Role in the exercise |
| --- | --- | --- |
| SRC-01 | [Historical expense SOP](01_Old_Expense_SOP.md) | Baseline approval, submission, and receipt rules. |
| SRC-02 | [Finance pilot announcement](02_Finance_Pilot_Announcement.md) | Formal Region A taxi expense exception. |
| SRC-03 | [Team chat excerpt](03_Team_Chat_Excerpt.md) | An informal, over-broad interpretation of the change. |
| SRC-04 | [Process-owner decision](04_Process_Owner_Decision.md) | Fictional authorized clarification of scope, resubmission, and controls. |
| SRC-05 | [IT service note](05_IT_Access_Note.md) | Source for IT-002. |
| SRC-06 | [HR workflow note](06_HR_Onboarding_Note.md) | Source for HR-003. |

Read the formal announcement alongside the chat excerpt. The chat does not establish a company-wide approval exception. The process-owner decision defines the final rules used in the example FIN-001 SOP. The [evidence register](../Evidence_Register.csv) records which claims were confirmed or rejected.
