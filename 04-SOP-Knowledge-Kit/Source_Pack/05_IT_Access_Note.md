# IT service workflow note · Access reset

**Northstar Services (fictional demonstration)**  
**Date:** October 20, 2026  
**Source reference:** SRC-05

The employee opens an IT Service Desk request for an account access reset. IT verifies the employee's identity using the company's approved identity-verification procedure, which is maintained separately. IT must not bypass identity checks at the requester's suggestion. After verification, IT initiates the authorized reset and asks the employee to confirm access through the standard sign-in flow. If verification fails or the account appears compromised, IT escalates to the Security team and does not perform a routine reset. The request and resolution are recorded in the service ticket.

**Owner:** IT Service Desk. **Approver:** IT Operations Lead. **Effective date:** October 21, 2026. **Review date:** March 31, 2027.
